# .vk classic

расширение для Chrome, которое возвращает современному ВКонтакте оформление 2011–2015 годов.

оно меняет шапку, меню, шрифты, цвета, аватарки и расположение колонок, но не вмешивается в данные аккаунта и работу самого сайта. расширение не использует аналитику, удалённый код или сторонние серверы.

![пример оформления](preview/classic-preview.png)

## установка

1. скачайте и распакуйте [`VK-Classic-2011-2015.zip`](VK-Classic-2011-2015.zip).
2. откройте `chrome://extensions`.
3. включите режим разработчика.
4. нажмите «загрузить распакованное расширение» и выберите папку `vk-classic`.
5. обновите вкладку `vk.ru` или `vk.com`.

настройки и дополнительные пояснения есть в [`vk-classic/README.md`](vk-classic/README.md).

## разработка

для самого расширения сборка не нужна. для тестов понадобятся Node.js 22+ и Python 3:

```sh
npm ci
npm test
npm run pack
```

это неофициальный проект, не связанный с администрацией ВКонтакте.
