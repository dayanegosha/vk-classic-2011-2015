# .vk classic

расширение для Chrome с оформлением ВКонтакте 2011–2015 годов: синяя шапка, белый фон, квадратные аватарки и компактное текстовое меню. работает с современными страницами ВК.

## установка

1. распакуйте ZIP. нужна папка `vk-classic` с файлом `manifest.json`.
2. в Chrome откройте `chrome://extensions`.
3. включите режим разработчика.
4. нажмите «загрузить распакованное расширение» и выберите папку `vk-classic`.
5. обновите вкладку `vk.ru` или `vk.com`.
6. через значок пазла в Chrome закрепите «ВК классика», чтобы настройки были под рукой.

при скачивании исходников с GitHub выбирайте внутреннюю папку `vk-classic`.

порядок установки соответствует [инструкции Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked).

## настройки

нажмите значок расширения. изменения сразу применяются ко всем открытым страницам ВК:

- **классический дизайн** — включение и выключение без перезагрузки.
- **ширина страницы** — 800, 900 или 1040 пикселей. по умолчанию 800, близко к оригиналу. в сообщениях и ленте с включённой правой колонкой расширение выделяет до 1040 px, чтобы две колонки не сжимались. размер ограничен шириной окна.
- **размер текста** — 11–14 пикселей. по умолчанию 11, как в старых стилях; семейство Tahoma → Arial → Verdana.
- **квадратные аватарки** — вернуть характерную форму старого ВК.
- **классическое меню** — скрыть значки и показать «мои друзья», «мои сообщения» и другие старые названия. сами ссылки и счётчики остаются родными.
- **классический профиль** — скрыть обложку и поставить фото слева от информации. можно выключить отдельно при экспериментальной компоновке профиля.
- **скрыть истории**, **убрать правую колонку в новостях** — компактная лента.

## ограничения

расширение меняет оформление доступных современных элементов. нынешние сообщения, друзья, посты, поиск и кнопки работают через сам ВК. оно не восстанавливает удалённые сервисом функции: старую стену, мнения, рейтинги или старые правила работы музыки. фотовьюер и видеоплеер сохраняют современное расположение.

пропорции и отдельные блоки зависят от текущей версии ВК. на 10 октября 2026 года адаптер учитывает публичную SPA-разметку с `#page_header`, `#page_layout`, маркерами `leftmenuitem-text`, `profile-header`, `profile-avatar` и `profile-narrow-column`, а также старую разметку разделов. переключение дизайна, динамическое меню, сохранение настроек и оформление проверены на локальном примере со структурой VKCOM kit. проверка в авторизованном аккаунте ещё не выполнена.

если после обновления ВК отдельный блок выглядит неправильно, можно временно выключить соответствующую настройку или весь дизайн. мобильная версия, страницы входа и сервисы на других доменах не оформляются.

## данные и разрешения

разрешение `storage` нужно для локального сохранения настроек. скрипт запускается только на `vk.ru`, `vk.com` и их `www`-вариантах; Chrome показывает доступ к этим сайтам при установке. расширение не делает сетевых запросов, не использует аналитику, не читает cookies и не отправляет содержимое ВК сторонним сервисам. серверы, ключи API и сборка для работы не нужны.

## удаление и обновление

для удаления выключите расширение, обновите открытые страницы ВК и нажмите «удалить» на `chrome://extensions`. после замены файлов нажмите кнопку обновления на карточке расширения и обновите вкладки ВК.

## диагностика

если блоки отображаются неправильно:

1. откройте профиль, дождитесь загрузки и нажмите в расширении «сохранить диагностику страницы».
2. повторите на странице новостей и в открытом диалоге.
3. передайте файлы `vk-classic-diagnostic-profile.json`, `vk-classic-diagnostic-feed.json`, `vk-classic-diagnostic-messages.json` разработчику вместе со скриншотами проблем.

отчёт содержит только техническую структуру компонентов, настройки, размер окна и параметры оформления до/после применения расширения. он не содержит текста сообщений и записей, фотографий, ссылок, адреса страницы, содержимого форм или динамических идентификаторов. сохраняется локально и автоматически никуда не отправляется. встроенные сторонние iframe отмечаются как изолированные, их содержимое не читается. при очень большой странице структура ограничена первыми 1800 элементами; в файле отмечается, если достигнут этот предел.

если JSON не появился в загрузках, нажмите «скачать JSON повторно». при ошибке обновите карточку расширения и вкладку ВК, затем повторите.

## источники

- [OldVK 61.0](https://github.com/Kesantielu/oldvk) — архивный GIF логотипа и ориентир для шрифта Tahoma / 11 px. сам код этого расширения не включён; логотип ВКонтакте остаётся изображением соответствующего бренда.
- [OldVK_Gold](https://github.com/BogdanSochivko/OldVK_Gold) — дополнительный образец оформления старых разделов. современный адаптер написан отдельно.
- [скриншот классического профиля](https://wylsa.com/wp-content/uploads/2016/08/vkontakte.jpg) и [история оформления](https://wylsa.com/new-design-vk/).
- [публичная страница ВКонтакте](https://vk.ru/durov) — структура современной оболочки.
- [VKUI](https://github.com/VKCOM/VKUI) — структура современных SplitLayout / SplitCol / HorizontalCell и публичные цветовые переменные светлой темы.
- [Chrome: content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts), [Chrome: storage](https://developer.chrome.com/docs/extensions/reference/api/storage).
